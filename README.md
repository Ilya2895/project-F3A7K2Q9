# Handmade Jewelry

Educational team project developed during the GoIT Fullstack course.

The project is a responsive one-page website for a handmade jewelry brand.

[View the website](https://ilya2895.github.io/project-F3A7K2Q9/)

- Tablet: from 768px
- Desktop: from 1440px
